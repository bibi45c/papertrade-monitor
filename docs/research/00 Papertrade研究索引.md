## 阅读口径

- **已验证事实**：官方文档、官方公开状态流、实际 API 和监控数据库记录。
- **测算假设**：手续费、滑点、持仓时长、50% 方向概率、未来交易活跃度等；均不代表个人实盘结果。
- **推断**：低名义仓位可能降低铸币成本、正资金费时 HL 空头有利等；需要执行和持续数据验证。
- **待确认**：个人排名、真实账户费率、实际成交价、分红领取与提现。
