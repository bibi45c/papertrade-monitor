2026-10-11 新增“拿 PAPER 划不划算”面板，没有 D1 表结构迁移：分钟级指标由网页另取最近 2 小时 `/api/history` 计算（每枚新 PAPER 对应质押收入、质押者拿走的亏损比例、每枚 PAPER 每小时分红、供应增长，需 48 分钟以上连续样本）；路径成本与磨损表用实时铸币率和交易参数；官方小时统计由采集器读取 `/query/protocol/history?interval=1h`，保留最近 8 个交易小时，写入快照 JSON 的 `protocolHours`，来源名 `protocolHistory`。口径见 [[06 对冲规则核查与盈利路径验证]]。

## 只读边界与已确认项目规则

已批准 GitHub + Cloudflare Worker/静态网页 + D1；预算是 Paper 1000 U，HL 另有资金。工具访问公开接口，不连接钱包、不签名、不提交订单。部署凭据沿用已经批准的权限，仅管理本项目；不写入源码、笔记或数据记录。

各来源保留来源时间、查询时间、区块或版本。未知/失败不能当零。PAPER 市价、铸币成本、待分配、已分配、个人现金收入分开。方案包含涨跌双分支、盈利折扣、深度、手续费、滑点、资金费和清算风险。公共 API 拒绝写入方法。

项目 `AGENTS.md` 当前仍标记首版待人工审核。用户的全局规则要求核心架构、迁移、安全边界与生产变更按授权范围执行；获批后的 AGENTS 修改须完整 diff 与针对性批准。本次未修改 AGENTS，沿用先前批准的同一项目发布权限。

## 运行与恢复

Node.js 22+，Wrangler 锁定 4.149.0，准确命令在项目 package.json。

```powershell
cd D:\code\web3\papertrade-monitor
npm run monitor -- --once
npm run dev
npm run check
npm test
npm run cloud:verify -- --public-dns
```

需要停止云端采集时移除本项目 Cron Trigger；网站可回退上一 Worker deployment，保留 D1。先导出 CSV/数据库，再另行决定数据删除。没有在本次执行停用、回退或删库；恢复操作仍应按届时用户授权执行。
